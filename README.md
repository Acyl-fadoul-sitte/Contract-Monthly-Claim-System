# Contract Monthly Claim System

## 📌 Project Overview
The Contract Monthly Claim System is a web application to manage contract claims efficiently. Users (Coordinators and Academic Managers) can submit, approve, and track monthly claims.

Built with **ASP.NET Core MVC** and **Entity Framework Core**.

---

## 🗂 Repository Contents
- **Source Code**: All project files including controllers, models, views.
- **README.md**: Documentation and instructions.
- **PowerPoint Presentation**: Explaining the system and architecture.
- **YouTube Video**: Demonstration of key functions (unlisted).

---

## 🎯 Key Features
- Role-based user authentication.
- Claim management: Add, edit, approve/reject claims.
- Monthly reports and data analysis.
- Secure database using SQL Server.
